# SOSRG Manifesto

This is not a production house.

This is not a casting website.

This is not a startup.

SOSRG exists to build India's most connected creative ecosystem,
starting from Bihar.

Everything on this website must reinforce that vision.

The website is not selling services.

It is inviting people into a movement.

Every screen should answer one question:

"Why should an artist believe that SOSRG can change their future?"

If a section cannot answer this question,
it should be redesigned or removed.

The website should feel like

Apple
×

A24
×

Netflix Documentary
×

National Geographic
×

Notion

instead of

Themeforest
×

Generic SaaS
×

Portfolio template

Every animation must have narrative purpose.

Every image must communicate emotion.

Every section must connect to the previous one.

Nothing should feel randomly placed.

No decorative UI.

No filler content.

No lorem-style marketing copy.

Every pixel must contribute to the story.
