Community API

Community 4 routes

Every route requires Authorization: Bearer <accessToken> — none of these four are public.
POST /v1/community/content-shares Share a YouTube link BEARER

Provisions the caller's profile if one doesn't exist yet, resolves the link to a canonical youtube.com/watch?v= URL, and publishes it as a post.

REQUEST BODY

FIELDTYPEREQ.NOTES
youtubeUrlstringyes≤ 2048 chars. Accepts youtube.com/watch, youtu.be, and /shorts/ links.
industryenumyesTheatre · Cinema · Literature · Music · Dance · Art & Design · Craft
captionstringno≤ 255 chars.

RESPONSE — 201

{
  "data": {
    "id": "uuid",
    "authorProfileId": "uuid",
    "authorDisplayName": "string",
    "authorProfileType": "string",
    "industry": "Music",
    "youtubeVideoId": "dQw4w9WgXcQ",
    "youtubeUrl": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
    "caption": "string|null",
    "createdAt": "ISO-8601"
  },
  "meta": { "requestId": "uuid", "nextCursor": null }
}
201 Shared400 VALIDATION_FAILED — INVALID_YOUTUBE_URL
PATCH /v1/community/content-shares/{id} Edit a share's industry or caption BEARER

PATH PARAMETER

FIELDTYPENOTES
iduuidThe content-share's id.

REQUEST BODY

FIELDTYPEREQ.NOTES
industryenumnoSame set as create.
captionstringno≤ 255 chars.

Owner-scoped: the update silently affects zero rows if the caller isn't the author, rather than leaking whether the post exists.

204 No Content404 RESOURCE_NOT_FOUND — masked: not found, or not yours
DELETE /v1/community/content-shares/{id} Remove a share BEARER

PATH PARAMETER

FIELDTYPENOTES
iduuidThe content-share's id.

Soft delete — sets status = "removed" and deleted_at, drops out of the feed. Same owner-scoped masking as the PATCH above.

GET /v1/community/feed Browse shared content, newest first BEARER

QUERY PARAMETERS

FIELDTYPEREQ.NOTES
industryenumnoFilter to one industry.
limitintegerno1–50, default 20.
cursorstringnoOpaque, from a prior response's meta.nextCursor.

RESPONSE — 200

{
  "data": [{
    "id": "uuid",
    "authorProfileId": "uuid",
    "authorDisplayName": "string",
    "authorProfileType": "string",
    "industry": "Music",
    "youtubeVideoId": "string",
    "youtubeUrl": "string",
    "caption": "string|null",
    "createdAt": "ISO-8601"
  }],
  "meta": { "requestId": "uuid", "nextCursor": "string|null" }
}

Ordered by created_at desc, id desc. Pass the returned nextCursor back in as cursor to page further; null means there's nothing more.

200 OK400 VALIDATION_FAILED — malformed cursor
